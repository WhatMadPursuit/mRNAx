## 1. 全局大图景：现在的系统是怎么运转的？（车间类比）

把设计一条商用级 mRNA 想象成**造一架既要飞得稳、又不能侵犯别人专利的精密无人机**：

1. **前台总控台（混合风格 Bio-CAD Web 工作台 + MCP / CLI）**
   - 线上地址：[https://whatmadpursuit.github.io/mRNAx/](https://whatmadpursuit.github.io/mRNAx/)（连接轻量控制面 `https://149-248-39-200.sslip.io:8443`）。
   - 采用清爽蓝白（Swiss Bio-CAD）为主界面，右上角可一键切换哑光石墨深色模式；微调参数（例如把禁用内切酶从 `BsaI` 改成 `BspQI`）后，会自动弹出 `v01 → v02` 同比例尺对比条与二维帕累托散点图，锁定过的氨基酸序列和化学修饰 100% 自动继承、绝不跑偏。
2. **图纸与门禁车间（确定性状态机 + 共享硬门 `ScopedConstraintEngine`）**
   - 不管是网页点击、命令行重放还是外部 AI 工具调用，最终都经过同一把「游标卡尺」：蛋白序列 100% 核对、`m1Ψ` 滑移位点（连续 `UUUU`）自动打断、跨区段/按作用域酶切零误杀零残留、8 条实核授权专利序列防碰撞（`patent_fto_guard_v2`），以及 12 个外部权威生物数据库（含版权自动防火墙）取证。
3. **发动机内循环车间（`G7` 真正升级的核心生成器，绝非「只打分不改序列」）**
   - 以前如果只换打分器、不改生成器，就好比「拿尺子在一堆随机零件里挑高个子」（我们严格将这种对照标注为 `本次未改善生成器`）。
   - 现在我们在生成零件的**内循环**里直接装上了导航仪：把人源 61 个密码子稳定系数 + 3,721 种前后双密码子衔接图谱、200×200 洁净人源 UTR 库、160 个人源结合蛋白（ATtRACT RBP）去衰减规则与 GC 稳态采样融合进**不分段全转录本联合采样**，并保证对照臂与升级臂直接 CDS 算子调用次数严格 1:1 相等（单链均为 `38` 次，双链均为 `72` 次）。
4. **多裁判风洞（纯商用洁净打分栈 + 云端 L4 GPU 零漂移核验）**
   - 日常毫秒级打分由零 GPU 商用洁净四头模型（5′UTR 翻译效率、CDS 稳定性、3′UTR 稳定性、Saluki 全长半衰期）按功能轴各司其职；
   - 重型深度学习结构与全长评估走云端一次性 Colab L4 GPU（MIT 协议 `Orthrus-6-track` 与 `structRFM` 化学修饰探针，以及 BSD-3-Clause `EternaFold v1.3.1` 零 ViennaRNA 依赖二级结构评估卡 `RC-004` 与运行时评估分发），跑完即销毁机器（当前 `0` 闲置云端 GPU），结果带双重校验码封存入 Google Drive。
5. **双层合规隔离墙（`G6` 序列 FTO + 算法方法 FTO + 多跳传递依赖拦截）**
   - 既查「交付出去的序列有没有撞上别人的授权专利权利要求」，也在运行清单（`RunManifest.optimization_mode_audit`）里诚实记录算法轨迹（区分实际执行的不分段全长帕累托优化、未执行阻断态 `not_executed` 与历史回填态 `unrecorded_legacy`，同时明确注明工程审计不替代目标法域专利律师法律意见）。
   - 自动递归扫描代码、权重、训练数据及多层传递依赖包（含 PEP 508 直接 URL 与 PEP 503 包名归一化），把披着宽松外壳却暗藏 `GPL/AGPL` 或非商用条款的陷阱（如 `varnaapi`、`helical`、`utr.lm` 等）全部挡在商用洁净轨之外。
